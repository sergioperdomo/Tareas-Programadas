# 📌 Task Manager – ICC Version

Aplicación web desarrollada en **Angular** para la gestión de tareas por usuario, con implementación de funcionalidades CRUD y rediseño visual adaptado a ICC.

---

## 🚀 Descripción

Este proyecto consiste en un sistema administrador de tareas que permite:

- ✅ Crear tareas  
- ✔️ Marcar tareas como completadas  
- 🗑 Eliminar tareas  
- 👤 Gestionar tareas por usuario  
- 📊 Interfaz tipo dashboard  
- 🎨 Diseño institucional personalizado  

Se aplicaron buenas prácticas de estructura de componentes, separación de responsabilidades y diseño responsive.

---

## 🛠 Tecnologías Utilizadas

- Angular  
- TypeScript  
- SCSS  
- HTML5  
- CSS Variables  
- Material Symbols (Google Icons)  

---

## 🎨 Características Implementadas

- ✔ Implementación de eliminación de tareas  
- ✔ Rediseño completo con identidad visual institucional ICC  
- ✔ Variables globales CSS para estandarización de colores  
- ✔ Layout tipo dashboard  
- ✔ Modal personalizado para creación de tareas  
- ✔ Sidebar de usuarios con estado activo  
- ✔ Efectos hover y transiciones suaves  
- ✔ Actualización de favicon institucional  
- ✔ Validación funcional completa del sistema

## ⚙️ Instalación

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/sergioperdomo/Tareas-Programadas.git
```

### 2️⃣ Instalar dependencias

```bash
npm install
```

### 3️⃣ Ejecutar el servidor de desarrollo

```bash
ng serve
```

### 4️⃣ Abrir en el navegador

```
http://localhost:4200/
```
